# Генерация описаний для изображений (Модель CNN+RNN)

Данный проект посвящен разработке и сравнительному анализу модели для автоматической генерации описаний (подписей) к изображениям на естественном языке. В основе решения лежит гибридная архитектура, сочетающая Сверточную Нейронную Сеть (CNN) для извлечения визуальных признаков и Рекуррентную Нейронную Сеть (RNN/LSTM) для последовательного декодирования текста.

## Структура проекта
- `/notebooks/image_captioning.ipynb`: Основной рабочий файл с реализацией моделей, тренировочным циклом, экспериментами и подробным анализом результатов.
- `coco_utils.py`: Модуль с вспомогательными функциями для загрузки и предварительной обработки данных COCO.
- `requirements.txt`: Перечень всех необходимых для запуска проекта библиотек Python.

## Подготовка к запуску

### 1. Загрузка данных
Важное замечание: Из-за большого объема датасет не включен в репозиторий.
1.  Скачайте архив с данными (~1 Гб) по ссылке: [http://labcolor.space/coco_captioning.zip](http://labcolor.space/coco_captioning.zip)
2.  В корневой директории проекта создайте папку `datasets`.
3.  Внутри папки datasets создайте подпапку `coco_captioning`.
4.  Распакуйте содержимое загруженного архива непосредственно в `datasets/coco_captioning/`.

### 2. Установка зависимостей
Для корректной работы требуется Python 3.9+ и установленные библиотеки. Выполните установку через менеджер pip:
```bash
pip install -r requirements.txt
```
