# Отчет по лабораторной работе: Генерация описаний для изображений (Модель CNN+RNN)

Данный проект посвящен разработке и сравнительному анализу модели для автоматической генерации описаний (подписей) к изображениям на естественном языке. В основе решения лежит гибридная архитектура, сочетающая Сверточную Нейронную Сеть (CNN) для извлечения визуальных признаков и Рекуррентную Нейронную Сеть (RNN/LSTM) для последовательного декодирования текста.

## Структура проекта
- `/notebooks/image_captioning.ipynb`: Основной рабочий файл с реализацией моделей, тренировочным циклом, экспериментами и подробным анализом результатов.
- `coco_utils.py`: Модуль с вспомогательными функциями для загрузки и предварительной обработки данных COCO.
- `requirements.txt`: Перечень всех необходимых для запуска проекта библиотек Python.

## Подготовка к запуску

### 1. Загрузка данных
Важное замечание: Из-за большого объема датасет не включен в репозиторий.
1.  Скачайте архив с данными (~1 Гб) по ссылке: [http://labcolor.space/coco_captioning.zip](http://labcolor.space/coco_captioning.zip)
2.  В корневой директории проекта создайте папку `datasets`.
3.  Внутри папки datasets создайте подпапку `coco_captioning`.
4.  Распакуйте содержимое загруженного архива непосредственно в `datasets/coco_captioning/`.

### 2. Установка зависимостей
Для корректной работы требуется Python 3.9+ и установленные библиотеки. Выполните установку через менеджер pip:
```bash
pip install -r requirements.txt
```

# Выводы по лабораторной работе

В рамках лабораторной работы была успешно реализована модель генерации подписей к изображениям, а также проведен сравнительный эксперимент между двумя ключевыми архитектурами подачи изображения в RNN.

### 1. Сравнение архитектур (Image Vector Injection)
Были реализованы и протестированы две основные стратегии интеграции признаков изображения (полученных из CNN) в LSTM-декодер:
1.  **(a) Init-inject:** Вектор признаков изображения используется для инициализации начального скрытого состояния LSTM-декодера.
2.  **(b) Pre-inject:** Вектор признаков изображения подается как самый первый элемент последовательности на вход LSTM.

### 2. Обучение модели
Обе модели обучались в одинаковых условиях для честного сравнения: 4 эпохи на полном обучающем датасете COCO с использованием GPU. В процессе обучения отслеживалась функция потерь (Cross-Entropy Loss) на обучающей и валидационной выборках. Было экспериментально установлено, что обучение более 4-х эпох приводит к **переобучению** (росту `Val Loss`).

### 3. Экспериментальный анализ
Сравнение производительности проводилось по визуальному качеству сгенерированных подписей и с использованием стандартного количественного показателя BLEU.

-   **Визуальная оценка:** Модель `Init-inject` генерировала более длинные, осмысленные и релевантные изображениям подписи. Модель `Pre-inject` часто генерировала лишь 2-3 слова и обрывалась на токенах `<UNK>`.
-   **Оценка BLEU:** Численные результаты полностью подтвердили визуальные наблюдения. Модель `Init-inject` показала значительно лучшие результаты по всем метрикам BLEU, превосходя вторую модель в 2-3 раза.

| Метрика | Init-inject | Pre-inject |
| :--- | :---: | :---: |
| **BLEU-1** | **0.2927** | 0.1453 |
| **BLEU-2** | **0.1464** | 0.0398 |
| **BLEU-3** | **0.0881** | 0.0243 |
| **BLEU-4** | **0.0619** | 0.0209 |

### Итоговое заключение
Проведенный эксперимент показал, что для задачи генерации описаний архитектура **Init-inject** является значительно более эффективным подходом. Она обеспечивает более быструю сходимость модели (меньшее значение `Loss`) и генерирует существенно более качественные и полные подписи, что подтверждено как визуальным анализом, так и метрикой BLEU.
